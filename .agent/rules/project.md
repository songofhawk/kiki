# Kiki 仓库上下文索引与边界约定

1. **设计与素材路径映射**：
   - 项目设计与交互规格见根目录 [kiki_v1.md](../../kiki_v1.md)（文档内提及的 `@docs/kiki-v1-design.md` 即指该文件）。
   - `reference/kiki/` 存放原始手绘视觉稿（视为只读源素材；工程裁剪/转换后的静态资源如 `kiki-states.png` 输出至 `assets/` 或前端静态目录）。
2. **单一事实源（SSOT）演进原则**：
   - 模块未实现前以 `kiki_v1.md` 为准；代码落地后，具体字段、类型与常量以**源码定义**为唯一事实源，仅在产品机制或架构发生实质变更时同步更新 `kiki_v1.md`。
   - `.agent/` 仅记录代码与文档无法自解释的仓库级特例与高频脚本，不复制业务规格，也不堆砌通用编程常识。
3. **本地数据隔离**：
   - 本地 SQLite 数据库及运行产物统一置于 `data/`（已在 `.gitignore` 忽略），切勿将 `.db`、`.env` 或运行期产物纳入版本控制。
